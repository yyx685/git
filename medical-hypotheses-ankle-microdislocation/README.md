1. **与既有概念的关系**：新增 2.2 节 + Table 1，正面区分 micro-dislocation 与
   - positional fault（Wikstrom & Hubbard 2010；Hubbard & Hertel 2008；Vicenzino 2006 等）
   - ankle microinstability（Vega 2021、2023）
